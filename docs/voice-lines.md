# تسجيلات الصوت (نطق الخيارات)

كل ملف = كلمة أو عبارة واحدة تُنطق حين يختارها لاعب. الكلمات المقترحة بلهجة خليجية خفيفة؛ غيّر النطق كما تحب، **لكن اسم الملف يبقى كما هو**. ما لا يوجد له تسجيل يُنطق بصوت الهاتف.

## طريقة التسجيل
- صوت شخص واحد لكل الملفات، بنفس المسافة من الميكروفون ونفس الارتفاع.
- مكان هادئ بلا صدى. تكفي أداة التسجيل في الهاتف.
- كل كلمة في ملف مستقل، بلا صمت طويل قبلها أو بعدها (نصف ثانية على الأكثر؛ أقصّه أنا إن لزم).
- أي صيغة: m4a أو mp3 أو wav.
- سمِّ الملف باسمه في الجدول (مثل `n7.m4a`). وإن صعبت التسمية، سجّل بالترتيب وأرسل القائمة، وأنا أسمّيها.

## لعبة 187 (السوم)
الملفات `s87`، `s90`، `s95`، `s100`، `s105`، `s110`، `s115`، `s120`، `s125`، `s130`، `s135`، `s140`، `s145`، `s150`، `s155`، `s160`، `s165`، `s170`، `s175`، `s180`، `s185`، `s187`: كل ملف يُقال فيه رقمه (مثلاً `s110` = «مية وعشر»). أي رقم آخر يُنطق بصوت الهاتف.
