# لعبة 187 - بيع وشراء

نسخة ويب عربية أولية (MVP) تعمل مباشرة بدون تثبيت.

## التشغيل
افتح الملف `index.html` في Chrome أو Edge.

## ما تم تطبيقه
- 4 أو 5 لاعبين.
- رزمة 40 ورقة.
- عند 4 لاعبين: 9 أوراق لكل لاعب + 4 أوراق في الميدان.
- عند 5 لاعبين: 7 أوراق لكل لاعب + 5 أوراق في الميدان.
- المزايدة من 87 إلى 187.
- كشف الميدان عند الوصول إلى 140.
- المشتري يأخذ أوراق الميدان ثم يعيد ورقة مخفية لكل خصم: 3 أوراق عند 4 لاعبين و4 أوراق عند 5 لاعبين.
- اختيار الحكم.
- إلزام اتباع النوع عند توفره.
- احتساب قوة الأوراق والنقاط.
- احتساب خسارة المشتري حسب: 187 - السوم، والخسارة تبدأ من +1.
- خيار -187 الكامل مع إلغاء نقاط الخصوم في الجولة.
- انتهاء المباراة عند +312 أو -312.


## واجهة الجوال
تم تحويل الواجهة إلى تصميم Mobile First يشبه تطبيقات الجوال:
- شاشة عمودية مناسبة للهاتف.
- أزرار لمس كبيرة.
- شريط تنقل سفلي.
- طاولة لعب مناسبة للشاشات الصغيرة.
- بطاقات قابلة للسحب أفقيًا.
- دعم PWA مبدئي عبر manifest وواجهة standalone عند إضافتها للشاشة الرئيسية.
